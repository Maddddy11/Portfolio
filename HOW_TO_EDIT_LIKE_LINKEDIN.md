## 🔐 Security & Login

### Dev Login (Current)
```
✓ No email verification
✓ Instant login
✓ Perfect for testing
✓ Session lasts 24 hours
```

### How It Works:
```
1. Click "DEV LOGIN" at /admin/login
2. JWT token created
3. Session stored in Redis
4. Valid for 24 hours
5. Edit buttons appear automatically
6. Click "Sign Out" to logout
```

## 🎯 Tips & Tricks

### Best Practices:
- ✓ Use clear, specific commands
- ✓ Include full text in quotes
- ✓ Always review before applying
- ✓ Use consistent formatting

### Avoid:
- ✗ Vague commands: "change stuff"
- ✗ Incomplete data: "update project"
- ✗ Special characters in commands
- ✗ Skipping the preview step

## 📊 File Structure

When you edit, you're modifying:

```
content/
├── hero.json           ← Home page profile
├── projects.json       ← Projects showcase
├── experience.json     ← Work history
├── publications.json   ← Research papers
└── profile.json        ← General profile
```

All files are **JSON format** and **editable via the chat interface**.

## 🆘 Troubleshooting

| Problem | Solution |
|---------|----------|
| "Edit buttons not showing" | Refresh page after login |
| "Changes didn't apply" | Click APPLY CHANGES button |
| "Session expired" | Go to /admin/login and login again |
| "Command not recognized" | Try simpler command like "change X to Y" |
