# Quick Reference: LinkedIn-Style Editing

## 🚀 Start Here

### Access Admin
```
Deployed: https://mayank-portfolio-theta-wheat.vercel.app/admin/login
Local:    http://localhost:3000/admin/login
→ Click "DEV LOGIN"
```

---

## 📍 Where Are the Edit Buttons?

| Page | Location | Section |
|------|----------|---------|
| **Home** | Next to "PORTFOLIO // 2025" | Hero/Profile |
| **Projects** | Next to "// PROJECTS" | All Projects |
| **Experience** | Next to "// EXPERIENCE" | Work History |
| **Research** | Next to "// RESEARCH" | Publications |

---

## ✎ How to Edit

```
1. Click "✎ EDIT" button on any section
2. Type your change in chat (e.g., "change tagline to: AI Engineer")
3. Review changes in preview
4. Click "APPLY CHANGES"
5. Done! Changes live instantly
```

---

## 📝 Edit Commands by Section

### Hero (Home Page)
```
"change tagline to: [your new tagline]"
"update description to: [your bio]"
"change title to: [your title]"
```

### Projects
```
"add [Project Name] to projects"
"change [field] to: [value]"
"update project description to: [description]"
```

### Experience
```
"add [Job Title] at [Company]"
"update company to: [Company Name]"
"change role to: [New Role]"
```

### Publications
```
"add research paper [Title]"
"update publication to: [Title]"
"change venue to: [Conference/Journal]"
```

## 🔧 Troubleshooting

| Problem | Solution |
|---------|----------|
| No edit buttons | Log in to admin first |
| Changes not showing | Click "APPLY CHANGES" button |
| Session expired | Go to `/admin/login` again |
